# Portfolio — Mayjhon V. Gabunada

Personal portfolio site for **Mayjhon V. Gabunada**, a Full Stack Web Development & Data Analytics student based in Cebu City, Philippines.

🔗 **Live site:** [mgabunad.github.io/portfolio](https://mgabunad.github.io/portfolio/)

## About

This site showcases my journey into web development and data analytics — background, skills, training, certifications, and projects — along with a live feed of my GitHub activity pulled directly from the GitHub API.

## Sections

- **About** — background and career path
- **Skills** — languages, frameworks, databases, and tools
- **Experience & Training** — coursework and work history
- **Certifications** — completed credentials
- **Projects** — featured builds
- **GitHub Activity** — live commit feed and contribution graph, updated in real time from the GitHub public API
- **Contact** — email, phone, and social links

## Built with

- HTML5 & CSS3 (custom, no framework)
- Vanilla JavaScript
- [GitHub REST API](https://docs.github.com/en/rest) for the live activity feed
- Fonts: Space Grotesk, Inter, JetBrains Mono
- Hosted on GitHub Pages
